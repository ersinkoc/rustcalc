# Roadmap

This is a direction, not a release-date promise. Discuss large features in an
issue before starting implementation.

## Implemented

- [x] Standard/scientific decimals, editable expressions and live results
- [x] Searchable/pinned history, memory and persistence
- [x] English/Turkish UI and dark/light themes
- [x] Units, 64-bit programmer tools and function plots
- [x] Opt-in verified self-update and PowerShell install/uninstall
- [x] Optional daily automatic update checks and installs
- [x] Tests, CI, packaging and contributor documentation

## Next validation and polish

- [x] Publish and verify the first stable release
- [x] Exercise a real upgrade between published releases
- [ ] Authenticode or independent signed update metadata
- [x] Screen-reader names for every control (checked with Windows UI Automation)
- [ ] High-contrast, touch and large-DPI validation; NVDA, Orca and VoiceOver passes
- [x] Converter: the value in every unit of a category
- [x] Workspace, zoom and settings shortcuts
- [ ] Configurable shortcuts
- [x] Undoable history actions and file export/import
- [x] Graph pan/zoom, improved discontinuities and multiple curves
- [x] Number display: digit grouping, decimal mark and fixed decimals
- [x] Named variables in the calculator
- [x] Interface scaling and system appearance

## Future exploration

- [x] Linux x64 and macOS (Apple silicon and Intel) distribution, installers and CI
- [x] Windows ARM64 and Linux ARM64 binaries
- [x] Signed programmer arithmetic and selectable word sizes
- [x] Numerical root finding (plot roots and intersections)
- [ ] Arbitrary precision
- [x] Date arithmetic and financial tools (Formulas workspace)
- [x] Custom formulas with templates and JSON sharing
- [x] Update rollback
- [x] Pressure, energy, power and more imperial units
- [ ] Currency conversion (opt-in network)
- [ ] Installer packages and package-manager distribution

Telemetry, accounts and mandatory cloud computation are not planned.
